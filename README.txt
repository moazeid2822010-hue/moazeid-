MOAZEID — موقع تعليمي عربي
================================
الملفات:
- index.html: صفحات ومحتوى الموقع.
- style.css: التصميم المتجاوب والخلفية التقنية المجردة.
- script.js: القائمة ومختبر الكود التجريبي.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح لمعاينة الموقع.
3) لرفعه على GitHub Pages، ارفع الملفات الثلاثة مباشرة إلى جذر المستودع (Root)، وليس داخل مجلد إضافي.
4) في GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.

ملاحظات:
- الخلفية سايبر تجريدية من دون تصوير أشخاص أو تضمين أدوات/علامات برمجيات خبيثة.
- مختبر الكود نموذج تعليمي محدود ولا ينفّذ مدخلات JavaScript عشوائية.
- الروابط المرجعية: MDN Web Docs، Python Documentation، OWASP، Git Documentation.
- المحتوى الحالي نموذج أولي قابل للتوسيع؛ أضف لكل درس مراجع ومراجعة تقنية قبل نشره كمادة موسوعية.
